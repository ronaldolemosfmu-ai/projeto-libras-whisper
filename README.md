# 🎤 Áudio → Texto → Libras (Whisper + VLibras)

Este projeto captura áudio do usuário, transcreve utilizando o modelo Whisper e exibe a tradução em Libras através do avatar do VLibras.

## 🚀 Tecnologias utilizadas

* Python
* Whisper (OpenAI)
* JavaScript (MediaRecorder API)
* VLibras

## 🧠 Como funciona

1. O usuário grava um áudio pelo navegador
2. O áudio é convertido para texto usando Whisper
3. O texto é exibido na tela
4. O VLibras traduz para Libras com avatar

## ▶️ Como executar (Google Colab)

1. Acesse o Google Colab
2. Faça upload do arquivo `projeto.ipynb`
3. Execute as células
4. Permita o uso do microfone

## 📌 Observações

* É necessário conexão com internet
* O modelo Whisper pode demorar na primeira execução
* A tradução para Libras depende da estrutura da frase
